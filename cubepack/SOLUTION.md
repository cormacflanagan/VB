## Packing

Each grid is one layer of the cube, z = 0 (bottom) first; x runs across, y down.

```
    z=0      z=1      z=2      z=3 
    DDIE     DIII     AAAI     JJJF
    DMEE     AMCC     AKGF     JKJF
    DMME     LCCF     LLGF     KKGG
    LMBE     LHBB     HHHB     KHGB
```
